# Application mobile — acheteurs

Flutter ou React Native. Parcours d'achat, panier, suivi de commande, suivi de livraison en temps réel.

**C'est la seule surface qui commande des repas aujourd'hui.** Le chiffrage de la livraison à la distance réelle n'existe que dans `MobileCheckoutEndpoints` ; le web et l'API publique refusent explicitement un panier de restauration faute de savoir le chiffrer.
