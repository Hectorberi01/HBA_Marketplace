# Configuration commune

Réglages transverses : tarification plateforme, devise, fuseau horaire.

**Le barème est le cas d'école.** Le monolithe a connu trois lectures concurrentes du taux de commission avant de les réduire à une seule source — et l'une d'elles acceptait « 10 » au lieu de « 0.1 », ce qui aurait multiplié la commission par cent. Distribuée, la même valeur doit venir d'un seul endroit, refuser les valeurs absurdes, et échouer au démarrage plutôt que de se replier sur un défaut.
